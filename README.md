# Cadeia

A simple autograd engine written from scratch in Rust.
This project is for educational purposes, not a production-grade machine learning library.
I got some inspiration from [this YouTube video](https://youtu.be/hL_n_GljC0I?si=S_J22T4WvQGWXOfO).

## Naming

The name `cadeia` comes from the fact that *regra em cadeia* means *chain rule* in Portuguese and the chain rule sits at the core of computational graphs.

## Main Components

The project is planned around four main components:

- **Matrix** -- storage, views, layouts, and matrix operations (e.g., addition).
- **Computational Graph** -- building the computational graph (which can be a neural network).
- **Fit** -- executing the training loop against a dataset.
- **Predict** -- running the graph against (possibly new) input data.

## Running
Once all components are ready, a convenient CLI tool will be made available.

## Examples and Tests

There will be examples to see the main components in action and learn how to interact with the API.

For instance, to run the matrix example:
```sh
cargo run --example matrix
```

For unit tests:
```sh
cargo test
```

## Benchmarks

The repository includes benchmarks for measuring the performance of key operations and tracking performance as the code changes.
The results are generated by `Criterion`. For example, to run the matrix multiplication benchmark:
```sh
cargo bench --bench matmul_bench
```
